# aod-scan

AOD label QR router. Piece-label QR codes point at
`https://altoptiondesign.github.io/aod-scan/?r=/<SCOPE record ID>`.
`index.html` sends iPhone/desktop to the Airtable Scan · Walls page and Android to the Scope · Scan record page.

This repo is PUBLIC (free GitHub Pages). Keep it to the router only — no AOD data, files or keys.
If Airtable changes its links, edit the page IDs at the top of the script in `index.html`. Printed labels never need reprinting.
